# Функциональное и нефункциональное тестирование сайта М.Видео 
📝 Описание проекта: <br>
Данный репозиторий содержит отчет и артефакты функционального и нефункционального тестирования сайта крупного интернет-магазина электроники Mvideo.

Цель тестирования: Проверка основных пользовательских сценариев (регистрация, авторизация, работа корзины) и оценка адаптивности сайта с помощью инструментов разработчика (DevTools).

🎯 План тестирования: <br>
В ходе работы были выполнены следующие проверки:

Функциональность авторизации и регистрации: Проверка входа по номеру телефона и SMS-коду.

UI и работа корзины: Добавление товара, изменение количества, проверка лимитов и удаление позиций.

Кросс-браузерность и адаптивность: Эмуляция мобильных устройств (Apple) через DevTools.

🛠 Окружение и инструменты: <br>
Тестируемый сайт: Mvideo.ru

Инструменты: Браузер (Chrome/Edge), DevTools (Device Mode), скриншоты, запись экрана.

Тип тестирования: Исследовательское (Exploratory), Функциональное, UI/UX.

🚀 Выполненные проверки и результаты: <br>
1. Авторизация и регистрация
Сценарий: Вход на сайт через кнопку «Войти», ввод номера телефона, получение SMS и ввод кода подтверждения.

Результат: ✅ Успешно.

Форма корректно валидирует ввод.

Код из SMS приходит своевременно.

После ввода кода происходит успешный вход в личный кабинет (подтверждено скриншотом и видео login (23.01.2026 17-57-33).wmv).

2. Работа корзины (Добавление/Удаление) <br>
Сценарий: Поиск товара (Телевизор Sber), добавление в корзину, изменение количества.

Результат: ✅ Успешно.

Товар добавляется корректно, счетчик на иконке корзины обновляется.

Найден лимит: При попытке добавить 10 единиц товара (Sber SDX-43UQ6032) система ограничивает количество. При добавлении другого товара (iPhone 17 Pro) лимит также составил 10 шт.

Удаление товара из корзины работает без ошибок.

3. Тестирование адаптивности (DevTools) <br>
Сценарий: Использование режима эмуляции устройств (Device Toolbar) в DevTools для проверки отображения на устройствах Apple (iPhone/iPad).

Результат: ✅ Успешно.

Верстка сайта адаптируется под размеры экрана.

Элементы навигации и карточки товаров остаются кликабельными и читаемыми.

Видео-подтверждение прилагается.
